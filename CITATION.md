# How to Cite GIS-B-ME

If you use GIS-B-ME in academic research, please cite:

Xuesong Xu; Junjie He; Chuntao Li; Xinggang Feng; Gang Xiao; Hongtao Tang.
(2026). *GIS-B-ME: A Semi-Synthetic
Benchmark for Elevator Preventive Maintenance Scheduling on Real-World Urban
Road Networks*. Version 1.0. GitHub.

Repository: `https://github.com/He-Junjie-92/GIS-B-ME`

Release: `https://github.com/He-Junjie-92/GIS-B-ME/releases/tag/v1.0`

Public dataset release: GIS-B-ME v1.0. Frozen data design: v3. Internal assembly
revision: v3.1.0.

When reporting computational experiments, specify GIS-B-ME v1.0 and the
instance identifiers. The validated reference results and final schedules are
part of this release. Retain the OpenStreetMap attribution described in
OSM_ATTRIBUTION.md and LICENSE.md.
